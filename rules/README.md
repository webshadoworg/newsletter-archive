# Rules

The operative rulebook for the GYE newsletters. Mirrored here from the bot workspace, which is where
it is edited; this copy is a read-only reference and is not linked from the site.

Eight files. Each is a list of rules, one line each, no stories. Read the one that covers what you
are about to do; you do not need the others.

| File | Read it when |
|---|---|
| [01-sensitivities.md](01-sensitivities.md) | Any copy that touches the struggle itself. **Read this one every issue.** |
| [02-voice.md](02-voice.md) | Writing or editing prose |
| [03-sources.md](03-sources.md) | Citing a mekor, a story, or a study |
| [04-members.md](04-members.md) | Printing a member's words or handle |
| [05-sections.md](05-sections.md) | Building the issue: headings, sections, TOC, lengths |
| [06-email-build.md](06-email-build.md) | Writing the HTML |
| [07-hebrew.md](07-hebrew.md) | Hebrew anywhere in an English email |
| [08-working.md](08-working.md) | Deciding whether something is mine to decide, flagging, publishing |

## What these files are

The operative rules. Short on purpose. Every rule here was asked for by Mendy, Rafael or a reader,
or was written after a mistake.

**The evidence behind them lives in `newsletter-rules.md` in the bot workspace**: the verbatim
quotes, dates, before and after. That file is not in this repo. Go there when you need to know *why*
a rule exists or what exactly was said. Never change a rule here without a ruling; if the two files
disagree, the long one is the record and this one has drifted.
