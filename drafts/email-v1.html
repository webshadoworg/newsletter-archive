The preheader is the only anonymity risk

The from name and subject are fixed strings we control. The preheader is the one slot that can carry the agent’s actual words onto a lock screen. Compare:

Generic: A reply is waiting for you on GYE.
Real first line: Hi, thanks for reaching out, and for trusting me with what’s…

The second one implies a confided problem to anyone holding the phone. Question 3.

Logo top-left and “Open conversation” — Mendy, Jul 30. The button label is a free win: it works whether there is 1 unread or 5, so the count pill needs no matching plural on the button. One string, no conditional. It also promises less work than “Read & reply” did, which is the whole reason for changing it.

The count line appears only when it is 2 or more. With one unread it is hidden entirely, so the email never says “1 message waiting.” The number counts unread messages in the conversation, not messages in this send — so it climbs on its own each time a member does not open the last one, which is exactly where a nudge is worth something. Wording set by Mendy Jul 30: {count} new messages from {name}. Because it is hidden at 1 it is always plural, so there is still no singular/plural conditional. Both states shown on page 3.

Two things to check on that wording. (1) Chaim’s name now appears three times in the top four lines — avatar block, headline, pill. If that reads heavy, the headline can drop the name and become “You have new messages waiting” once the pill is showing. (2) “from Chaim” is wrong if the conversation was handed to another agent mid-thread and some unread messages are someone else’s. Safe wording for that case only: “5 new messages in your conversation.”

No reply notice, per Mendy Jul 30. The line under the button is gone. Replies still land in help@gye.org, which the team already monitors, and get hand-carried into the support system — the email just doesn’t mention it. If a notice ever goes back in, do not write “replies aren’t seen” — it would be false, and a member who cannot get into the app would read it and say nothing at all.
